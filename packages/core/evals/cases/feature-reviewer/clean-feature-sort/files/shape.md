# Shape: Sort the list by title

- AC-1: WHEN the person chooses "Sort by title", THE list SHALL show the books in title order, ignoring case.
- AC-2: WHEN the person adds a book while sorted, THE list SHALL stay in title order.
- AC-3: WHEN the person chooses "Sort by title" again, THE list SHALL return to the order the books were added.
- AC-4: WHEN the person prints the list, THE printout SHALL show the books in the same order as the list.
